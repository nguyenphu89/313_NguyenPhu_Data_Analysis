##  Công cụ & Thư viện sử dụng
Dự án sử dụng các thư viện phổ biến trong Python cho khoa học dữ liệu:

- `numpy` – Xử lý mảng số học hiệu quả  
- `pandas` – Phân tích và thao tác dữ liệu dạng bảng  
- `matplotlib` – Trực quan hóa dữ liệu cơ bản  
- `seaborn` – Biểu đồ nâng cao và phân tích thống kê  
- `scipy` – Hỗ trợ phân tích thống kê và tính toán khoa học  
- `jupyter notebook` – Môi trường viết mã, hiển thị kết quả và giải thích trực quan
